# Nonspatial morphology measurements

- `morphology_rois.csv`: torso crops in reconstruction-image pixels and source hashes.
- `per_image_traits18.csv`: 18 measurements for each reconstructed stripe image.
- `identity_traits18.csv`: identity-mean measurements.
- `standardized_traits18.csv`: standardized identity-mean measurements.

ROI coordinates refer only to image pixels. The tables contain no geographic
positions, camera-location links, terrain or map data.
